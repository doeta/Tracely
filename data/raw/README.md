# Raw Event Log Directory (`data/raw/`)

Tempatkan file event log XES standar IEEE (`.xes` atau `.xes.gz`) pada direktori ini.

- File dataset berukuran besar (`*.xes`, `*.xes.gz`, `*.xml`) diabaikan oleh Git melalui `.gitignore`.
- Gunakan menu **Workspace -> Projects** atau tombol **Import Event Log** pada aplikasi desktop **Tracely** untuk memuat dataset dari folder ini.
