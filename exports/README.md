# Export Output Directory (`exports/`)

Direktori default untuk menyimpan hasil ekspor dari aplikasi **Tracely**:

- `analysis_summary.csv` — Ringkasan metrik, aturan, denominator, persentase, dan mean cycle time.
- `case_evidence.csv` — Bukti level case dan event (`evidence_json`) untuk setiap modul analisis.
- `tracely_analysis_report.pdf` — Laporan analisis otomatis siap cetak dalam format PDF.
